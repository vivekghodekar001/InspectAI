MODEL NOTES / 03

A reference for normal.

The model compares image features with a memory of normal bottles.

ResNet18 / frozen features

Find the difference.
Review the image.

Defects can vary. This approach builds its reference from normal images, then looks for local features that differ from that reference.

Scores are distances.
Human review remains part of the workflow.
  1. 01

    Extract local features

    A frozen ImageNet-pretrained ResNet18 reads the image at two feature scales. Inputs are resized to 192 × 192 pixels.

  2. 02

    Compare with normal patches

    Features are projected to 64 dimensions and compared with a memory of 6,000 normal patches using nearest-neighbor distances.

  3. 03

    Score and review

    The nine most unusual patch distances are averaged. The decision threshold is the 95th percentile of scores from separate normal calibration images.

About this implementation

A compact patch-memory baseline with a pretrained backbone. It does not fine-tune the neural network or implement the full published PatchCore method. The included evaluation covers MVTec AD bottles only.
