THE METHOD

Learn normal.
Find what differs.

No defect examples are used to build the memory bank. The image-level decision threshold is selected using a separate set of normal images.

  1. ExtractA frozen ImageNet ResNet18 extracts multiscale image features.
  2. CompareLocal patches are compared with a memory of normal bottle features.
  3. ReviewThe most unusual patches determine the score and guide visual review.
